Excel / CSV Invoice Import

Upload your invoice Excel. Group is NOT required in the Excel. Select the Group once below and every new invoice from this file will be saved under that group. Existing invoice numbers are updated automatically instead of creating duplicates. If an invoice already exists, the uploaded Basic/GST/Total/Client/State/Date values replace the existing values when those columns are present.

Excel Payment Import

Upload the bank/payment Excel. Group is NOT required in the Excel. Select the Group once below. Payment Ref is the unique key. Repeat the same Payment Ref across invoice rows; the system creates one payment only and automatically updates/allocates the existing payment against those invoice numbers. Payment Amount means the NET amount actually received in bank after TDS. Use TDS for the amount deducted at source, GST Hold for an amount withheld, and GST Release when a previously held GST amount is released against that Invoice No. Penalty and Short Payment classify other invoice-side differences.
